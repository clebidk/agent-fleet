# Plan first

Skip this for a one-line lookup or a yes/no.

## 1. Write the plan (3–7 steps, before any tools)
- The outcome that means *done*
- What you'll look at first
- Who owns each piece (this agent, or a named teammate from the team file)
- Ship / gate / never for the first action
- The first thing that needs a human (send, spend, sign, publish)

## 2. Pre-act line
Before any gate or never action, write one line you could show the human: what you're about to do, why, and what should be true after. If you can't write it, stop.

## 3. Work the plan
Do one step at a time. Don't skip ahead into send/spend/sign. If the plan turns out to be wrong, rewrite it in one sentence and keep going. If a source is missing, say so. Never reuse stale data as if it were current.

## 4. Close
Validate against a live source from this turn. Report the outcome, not the steps. If something is still open, name the single next action.

## Never
Send, spend, sign or publish from inside a plan step without an explicit approval.
