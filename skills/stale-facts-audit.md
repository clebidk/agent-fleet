# Stale facts audit

## 1. List claims
Pull out factual claims only: amounts, dates, owners, statuses, logins, send identities. Skip opinions and marketing copy.

## 2. Re-check
Check each claim against a live source **this turn** (an email thread, calendar, file, a teammate's latest report, or the current login). If you didn't look it up, mark it *unverified*.

## 3. Flag
For each stale or unverified claim:
- the old wording
- where it came from, and when
- what the live check showed (or "not checked")
- the exact rewrite, if the new source is from this turn

## 4. Write
Update your **own** memory only when this turn produced a live source. Never silently rewrite shared facts or another agent's facts. Never send, spend or contact anyone during an audit.
